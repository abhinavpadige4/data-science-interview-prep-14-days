## Study Plan Overview

This 14-day plan covers:
- **Python Fundamentals**: Data structures, control flow, OOP, error handling
- **Statistics**: Descriptive statistics, probability, distributions, hypothesis testing
- **Machine Learning**: Supervised learning, classification, evaluation metrics
- **SQL**: Query optimization, data manipulation, joins
- **Data Structures**: Arrays, strings, trees, linked lists
- **Algorithms**: Sorting, searching, dynamic programming, greedy approaches

## How to Use This Repository

1. Each day's solution is in the `solutions/` directory
2. Files are named according to the day and problem (e.g., `001_two_sum.py` for Day 1)
3. Each solution includes:
   - Clean, readable Python implementation
   - Time and space complexity analysis
   - Test cases to verify correctness
   - Detailed comments explaining the approach

## Running the Solutions

To run any solution:
```bash
python solutions/001_two_sum.py
```

## Complexity Analysis

All solutions are optimized for:
- **Time Complexity**: O(n) or better for linear problems
- **Space Complexity**: O(1) or O(n) as appropriate
- **Readability**: Clean, well-commented code
- **Correctness**: Handles edge cases and edge conditions
